# دليل رفع منصة FacePrompt على Netlify في 10 ثوانٍ 🚀

تم دمج مشروع **FacePrompt** بكافة تصاميمه ووظائفه وقوالبه والذكاء الاصطناعي الخاص به في ملف واحد ذاتي التشغيل بالكامل باسم:
`index.html`

---

### طريقة الرفع المباشر على Netlify (سحب وإفلات بدون أي أوامر):

1. افتح موقع Netlify Drop في المتصفح:
   👉 **https://app.netlify.com/drop**
2. اسحب مجلد `netlify_single_file` بالكامل (أو مجلد `dist`) وأفلته داخل الصفحة.
3. أو اسحب ملف `index.html` مباشرة.
4. مبروك! سيعمل موقعك فوراً وبشكل دائم ومجاني مع رابط مباشر خاص بك (مثل: `https://faceprompt.netlify.app`).

---

### الميزات المضمنة داخل ملف index.html المدمج:
- ✅ كافة أكواد JavaScript ومكتبات React 19 و Motion.
- ✅ كافة استايلات Tailwind CSS والألوان (النمط الأبيض والنمط الخمري الملكي).
- ✅ كافة أيقونات Lucide وعناصر الواجهة الفاخرة.
- ✅ نظام المقارنة بين كواليس الاستوديو ونتائج الستوري (9:16).
- ✅ محرك الذكاء الاصطناعي التشخيصي **بروتو (Proto AI)** يعمل بالكامل داخل المتصفح بدون الحاجة لأي خادم أو backend.
- ✅ حفظ البيانات محلياً (Local Storage).
- ✅ ملف `_redirects` لمنع أخطاء التوجيه 404 عند التنقل بين الصفحات.
